RGPD

Politique de confidentialité

Comment Connect collecte, utilise et protège les données envoyées via le formulaire de contact.

Responsable du traitement

Valentin Turpin — Connect, entreprise individuelle (auto-entrepreneur), basée à Aix-en-Provence, Bouches-du-Rhône, France.

Données collectées

Via le formulaire de contact, Connect collecte uniquement les informations suivantes :

  • Nom et prénom
  • Nom de l'entreprise (optionnel)
  • Adresse email
  • Numéro de téléphone (optionnel)
  • Type de besoin
  • Contenu du message

Aucun cookie publicitaire n'est déposé sur le site.

Finalité

Ces données sont utilisées exclusivement pour répondre à votre demande, échanger avec vous et, si nécessaire, engager une relation commerciale.

Base légale

Le traitement repose sur votre consentement explicite, recueilli via la case d’acceptation obligatoire du formulaire (article 6.1.a du RGPD).

Durée de conservation

Les données sont conservées pendant 3 ans maximum à compter du dernier échange.

Destinataires

Les données sont traitées uniquement par Valentin Turpin. Elles ne sont ni vendues, ni louées, ni cédées. Le formulaire utilise l'intermédiaire technique Web3Forms.

Vos droits

Conformément au RGPD, vous disposez d'un droit d'accès, de rectification, d'effacement, de limitation, d'opposition et de portabilité. Pour exercer vos droits : valentin@connect-affaires.fr.

Sécurité

Le site utilise une connexion sécurisée en HTTPS. Les données sont transmises via des services sécurisés.

Réclamation

Vous pouvez adresser une réclamation à la CNIL : www.cnil.fr.
